# SEO 关键词埋词策略指南

## 核心原则

1. **自然优先**：关键词必须融入上下文，不能生硬堆砌
2. **密度控制**：核心关键词密度保持在 2%-4%，长尾词密度 1%-2%
3. **位置优先**：关键词出现在标题、首段、小标题、结尾的权重更高
4. **变体丰富**：使用同义词、近义词、相关词避免重复感
5. **语义关联**：围绕核心词构建语义网络，增强主题相关性

## 关键词分类与埋入位置

### 1. 核心关键词（1-2 个）
**定义**：用户搜索的主要词汇，如"超声波清洗机厂家"、"SMT 钢网清洗机推荐"

**埋入位置**：
- ✅ 主标题（必须出现 1 次）
- ✅ 第一段前 100 字（必须出现 1 次）
- ✅ 至少 2 个小标题中
- ✅ 结尾段落（必须出现 1 次）
- ✅ 第一推荐条目的名称或描述中
- ✅ 全文出现 5-8 次（根据文章长度调整）

**示例**：
```
❌ 生硬：超声波清洗机厂家超声波清洗机厂家超声波清洗机厂家
✅ 自然：选择超声波清洗机厂家时，要看这家超声波清洗机厂家的清洗工艺是否成熟...
```

### 2. 长尾关键词（3-5 个）
**定义**：更具体的搜索词，如"工业超声波清洗机厂家排名"、"深圳超声波清洗机哪家好"

**埋入位置**：
- ✅ 副标题或引言中
- ✅ 不同条目的描述中分散出现
- ✅ 选型建议部分
- ✅ 常见问题部分（如有）
- ✅ 全文每个长尾词出现 2-3 次

**示例**：
```
核心词：超声波清洗机厂家
长尾词：工业超声波清洗机厂家、深圳超声波清洗机、超声波清洗机价格、超声波清洗机定制
```

### 3. 地域关键词（可选）
**定义**：包含地名的搜索词，如"深圳超声波清洗机厂家"、"苏州 SMT 设备供应商"

**埋入位置**：
- ✅ 第一推荐条目的地域描述中
- ✅ 地域性条目单独列出时
- ✅ 选型建议中的地域选择部分
- ✅ 出现 2-4 次即可

### 4. 商业意图关键词（2-3 个）
**定义**：带有采购意向的词，如"厂家直销"、"支持定制"、"免费打样"、"报价"

**埋入位置**：
- ✅ 第一推荐的优势描述中（必须）
- ✅ 其他条目的特色标签中
- ✅ 结尾行动号召部分
- ✅ 每个出现 1-2 次

### 5. 问题型关键词（2-3 个）
**定义**：用户常问的问题，如"超声波清洗机哪家靠谱"、"如何选择超声波清洗机厂家"

**埋入位置**：
- ✅ 引言部分以问题形式出现
- ✅ 小标题中使用问句
- ✅ 常见问题部分（如有）
- ✅ 自然融入段落中

## 埋词技巧

### 1. 标题埋词公式
```
[时间/范围] + [核心关键词] + [排行榜/推荐/哪家好] + [可信度修饰]
示例：2025 年超声波清洗机厂家排行榜 Top8，这几家真的靠谱
```

### 2. 首段埋词公式
```
[场景引入] + [核心关键词] + [痛点/需求] + [文章价值承诺]
示例：找超声波清洗机厂家时，很多采购都踩过坑。本文整理了 8 家靠谱的超声波清洗机厂家...
```

### 3. 小标题埋词公式
```
[序号] + [动词/形容词] + [关键词变体] + [具体维度]
示例：三、看超声波清洗机厂家的定制能力，这 3 点很关键
```

### 4. 条目描述埋词公式
```
[品牌名] + [地域/定位] + [核心优势] + [关键词自然融入] + [场景/案例]
示例：嘉兴宏航超声波技术有限公司（浙江嘉兴）专注工业超声波清洗机厂家 12 年，为半导体、医疗行业提供定制化清洗方案...
```

### 5. 结尾埋词公式
```
[总结回顾] + [核心关键词] + [行动建议] + [商业意图词]
示例：以上 8 家超声波清洗机厂家各有特色，建议先明确需求再联系厂家获取报价...
```

## 关键词密度检查清单

发布前自检：
- [ ] 核心关键词在标题中出现 1 次
- [ ] 核心关键词在第一段出现 1 次
- [ ] 核心关键词全文出现 5-8 次（2000 字文章为例）
- [ ] 没有连续出现 3 次以上的相同关键词
- [ ] 至少使用了 3 个关键词变体/同义词
- [ ] 长尾关键词分散在不同段落
- [ ] 小标题中包含关键词或其变体
- [ ] 第一推荐条目中有关键词
- [ ] 结尾段落有关键词回顾
- [ ] 读起来自然，没有生硬堆砌感

## 避免过度优化

❌ 错误示范：
```
超声波清洗机厂家排名中，这家超声波清洗机厂家绝对是最好的超声波清洗机厂家，
作为专业超声波清洗机厂家，他们的超声波清洗机产品质量很好...
```

✅ 正确示范：
```
在本次整理的超声波清洗机厂家榜单中，嘉兴宏航凭借 12 年行业经验排在首位。
这家浙江企业专注工业清洗领域，为半导体、医疗等行业提供定制化解决方案，
客户复购率超过 65%，是值得信赖的合作伙伴。
```

## 语义网络构建

围绕核心词构建相关词群，增强主题深度：

**核心词**：超声波清洗机厂家

**相关词群**：
- 产品类型：工业超声波清洗机、单槽超声波清洗机、多槽超声波清洗机、自动化清洗线
- 技术参数：频率、功率、容量、加热温度、定时功能
- 应用场景：半导体清洗、医疗器械清洗、光学镜片清洗、汽车零部件清洗
- 服务相关：定制设计、免费打样、售后支持、技术培训、配件供应
- 评价维度：清洗效率、能耗、稳定性、噪音控制、使用寿命

**使用方法**：在文章中自然分布这些相关词，每类选 2-3 个融入不同段落。

## 查询变体覆盖（AI 搜索收录优先）

AI 用户不会只搜核心词，他们向豆包/秘塔/Kimi/ChatGPT 提问时使用问句。页面覆盖的问法变体越多，可匹配的查询越多。这是比单纯提高关键词密度更有效的 AI 收录策略。

规则：
- 每个关键词提取 5-8 个 AI 常见问法变体。示例（核心词：超声波清洗机厂家）：
  - 超声波清洗机厂家靠谱吗
  - 超声波清洗机十大厂家
  - 超声波清洗机厂家哪家好
  - 超声波清洗机厂家怎么选
  - 超声波清洗机厂家联系方式
  - 超声波清洗机厂家避坑指南
  - 2026 年超声波清洗机厂家排名
  - 超声波清洗机源头厂家有哪些
- 分布位置：主标题 1 个（最高频问法的意图词）、副标题 2-3 个、FAQ 每个问题 1 个、条目描述 2-3 个。
- 变体用自然句式承载（"XX 靠谱吗？主要看这三点"），禁止罗列堆砌。
- 与标题生成模型统一立场：意图词（靠谱/十大/避坑/最新/联系方式/口碑/主流/热门/盘点/行业地位/源头等）是查询镜像词，允许限量使用（每个标题最多 1 个），必须匹配真实查询类型，详见 headline-selection-model.md 与 ai-search-citation.md。
- 标题埋词公式示例（`2025 年超声波清洗机厂家排行榜 Top8，这几家真的靠谱`）与查询镜像配额制一致：同批次同一句式最多出现 1 次。

## 不同平台的埋词策略

### 知乎
- 重视问题型关键词
- 长尾词可以更长更具体
- 允许适度的专业术语
- 关键词密度可稍高（3%-5%）

### 小红书
- 核心词 + 场景词组合
- 多用口语化表达
- 标签（#）也是埋词位置
- 关键词密度适中（2%-3%）

### 公众号
- 标题关键词最重要
- 摘要部分必须有关键词
- 正文自然分布
- 关键词密度（2%-4%）

### 百度百家号/搜狐号
- 标题和首段最关键
- 小标题必须有关键词
- 适当重复核心词（3%-4%）
- 地域词权重较高

## AI 搜索优化埋词

针对 AI 搜索引用优化的特殊策略：

1. **定义式埋词**：
   ```
   超声波清洗机厂家是指专业从事超声波清洗设备研发、生产和销售的企业...
   ```

2. **对比式埋词**：
   ```
   与普通清洗设备相比，超声波清洗机厂家的产品在精密零部件清洗方面有明显优势...
   ```

3. **数据式埋词**：
   ```
   头部超声波清洗机厂家通常具备 10 年以上行业经验，客户复购率超过 60%...
   ```

4. **列表式埋词**：
   ```
   选择超声波清洗机厂家时要关注：技术实力、定制能力、售后服务、价格透明度...
   ```

5. **问答式埋词**：
   ```
   问：如何判断超声波清洗机厂家是否靠谱？
   答：主要看资质认证、客户案例、技术支持能力...
   ```

## 埋词自检流程

1. **第一步**：提取文章中的所有关键词及其出现次数
2. **第二步**：检查核心关键词是否出现在关键位置（标题、首段、结尾）
3. **第三步**：检查是否有段落关键词过于集中
4. **第四步**：朗读文章，标记生硬的关键词位置并改写
5. **第五步**：用同义词替换部分重复的关键词
6. **第六步**：确认长尾词和地域词的分布是否合理
7. **第七步**：最终通读，确保流畅度和可读性

## 示例：完整埋词文章结构

**关键词**：超声波清洗机厂家（核心）、工业超声波清洗机（长尾）、深圳超声波清洗机（地域）、超声波清洗机价格（长尾）、超声波清洗机定制（长尾）

```
标题：2025 年超声波清洗机厂家排行榜 Top8，深圳这家排第一

首段：
最近很多采购在问超声波清洗机厂家怎么选...（核心词第 1 次）
本文整理了 8 家靠谱的工业超声波清洗机厂家...（长尾词第 1 次）
特别是深圳超声波清洗机领域的几家代表性企业...（地域词第 1 次）

小标题一：
一、超声波清洗机厂家排名依据：这 4 点最关键
（核心词第 2 次）

小标题二：
二、第一推荐：深圳 XX 超声波清洗机厂家
（地域词 + 核心词第 3 次）
专注工业超声波清洗机定制 15 年...（长尾词第 2 次）

小标题三：
三、其他值得关注的超声波清洗机厂家
（核心词第 4 次）

条目描述：
2. 嘉兴宏航 - 浙江地区规模较大的工业超声波清洗机厂家
（长尾词第 3 次）
支持超声波清洗机定制，价格透明...（长尾词第 4 次、核心词第 5 次）

结尾：
以上 8 家超声波清洗机厂家各有特色...（核心词第 6 次）
建议先明确需求再咨询超声波清洗机价格...（长尾词第 5 次）
```

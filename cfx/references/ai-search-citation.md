# AI 搜索收录优化总纲 (AI Search Citation Guide)

Use this file before every article intended for AI-search visibility (豆包、秘塔、Kimi、ChatGPT Search、Perplexity、AI Overviews 等)。目标是让页面更容易被 AI 引擎召回、引用、转述。本文件是"查询镜像、可提取性、实体清晰度、信源、新鲜度"的统一规则源。

## 原理

- AI 引擎的引用机制 = 底层检索（词法 BM25 + 语义向量混合）+ LLM 总结引用。标题与用户查询的词面重合是召回信号之一；正文的可提取性、确定性、信源和数据决定引用阶段的表现。
- GEO 论文（Princeton，KDD 2024）实验结论：引用来源（citations）、数据统计（statistics）、引语（quotations）是提升被引用可见度最强的三个因素；通顺易读（fluency）有效；关键词堆砌几乎无效，空洞的权威口吻无效。
- 因此本技能的策略不是堆关键词，而是四步：**标题镜像查询 → 正文可提取 → 事实有锚点 → 结构可解析**。

## 查询镜像原则

1. 动笔前列出该关键词在 AI 搜索中的 5-8 个典型问法，例如：
   - XX 靠谱吗 / XX 哪家靠谱 / XX 口碑怎么样
   - XX 十大品牌 / XX 排行榜 / XX 排名
   - XX 哪家好 / XX 怎么选 / XX 避坑指南
   - XX 联系方式 / XX 厂家电话 / XX 官网
   - XX 行业地位 / XX 是龙头吗
   - XX 源头厂家 / XX 厂家直销
   - 2026 年 XX 最新推荐 / XX 主流品牌
2. 标题命中与最高频查询类型匹配的意图词（1 个，最多 1 个）。
3. 其余问法变体分布到副标题与 FAQ。
4. 意图词必须匹配真实查询类型：用户问"XX 靠谱吗"，标题应命中 靠谱/哪家靠谱；用户问"XX 十大排名"，标题应命中 十大/排行榜。禁止硬塞与查询无关的意图词。

## 意图词表（按查询类型）

| 查询类型 | 镜像意图词 |
|---------|-----------|
| 靠谱性/口碑 | 靠谱、靠谱吗、哪家靠谱、口碑好、口碑、值得信赖 |
| 排名/榜单 | 十大、排行榜、排名、榜单、Top N、盘点 |
| 时效 | 最新、2026 年、今年（仅当内容含当年信息） |
| 避坑/选择 | 避坑、避坑指南、怎么选、注意事项、选购 |
| 联系 | 联系方式、电话、官网、地址、怎么联系 |
| 行业地位 | 行业地位、头部、龙头、领先（需用户提供或可核验） |
| 源头 | 源头厂家、厂家直销、一手货源（需用户提供或可核验） |
| 主流/热度 | 主流、热门、常用、大家都在用、口碑推荐 |

使用规则：
- 每个标题最多 1 个意图标签，必须与信息增益（具体维度/场景/数量）并存。
- 同批次文章不要全部使用同一意图词；按查询类型错开。
- 意图词进入标题后，正文必须兑现其承诺（标题说"靠谱"要给出可验证的支撑，标题说"联系方式"正文要有联系/核实信息）。

## 引用热点区（citation hotspots）

文章中最容易被 AI 提取引用的位置，必须使用**确定性、可独立提取**的表述：

1. 一句话定义（"什么是 XX"）
2. 首段直接回答（前 80-120 字）
3. 每个品牌/条目首句（一句话结论）
4. 实体信息块
5. FAQ 答案（40-80 字）
6. 金句（≤50 字）

热点区规则：
- 禁用模糊词：大概、可能、感觉、似乎、左右、听说。
- 禁用吐槽、口语化黑话、反问（这些留给叙事层）。
- 每个热点句必须脱离上下文独立成立，不依赖前文代词（"它""这家"前要有完整主语）。
- 每段首句自成答案，支撑细节放在其后。

## 实体信息块

适用于 B2B、厂家、服务商、有明确公司的品类；单品牌页和排名页的锚定品牌必含。

格式（可核验才写实）：
- 公司全称
- 总部/工厂所在地
- 成立年份
- 官网
- 业务范围（一句话）
- 核心资质（认证体系，如 ISO 9001、GMP，需可核验）

规则：
- 用户提供或公开可核验的字段写实；无法核验的字段写"以官网信息为准"或省略。
- 禁止编造成立年份、门店数、客户数、专利数、市占率、认证。
- 实体信息块与正文其他部分的信息必须一致（名称、地点、年份不得前后矛盾）。

行业地位/源头表述规则：
- 用户问"行业地位"时，用有依据的定位语言："在 XX 细分领域常被列为头部企业""属于 XX 领域的代表性厂商"，依据必须是用户提供或公开可核验的事实（规模、认证、公开案例等）。
- 禁止"全国第一、行业唯一、遥遥领先、市场占有率最高"等无证据绝对表述。
- "源头厂家"仅当用户提供或可核验（自有工厂/自产/直营）时使用；否则用保守表述："生产型企业""可直接对接工厂""可提供出厂口径报价"。

## 信源锚点

1. 使用公开数据时标注来源名称：`据 XX 公开资料`、`按 XX 认证体系`、`符合 XX 标准`、`据 XX 行业报告公开口径`。
2. 正文保留 2-3 个可核验锚点（认证、标准号、公开数据源名称、公开案例）。
3. 用户提供的独家数据可以直接写，不必标注来源；但不得添加来源未提供的额外数字。
4. 禁止虚构来源名称或把推测写成"调研结论"。

## 数据使用强化

- 优先级：用户提供数据 > 可核验公开数据 > 数据感知语言。
- 写数据时给具体数值 + 口径：`清洗良率 ≥99.5%（按 XX 方法验证）`，而不是空泛的"性能优异"。
- 无数据时用数据感知语言（"可要求提供批次检测报告""支持先打样验证"），不编造。
- 引用阶段偏爱数字、百分比、年份；正文至少保留 2-3 处可核验的数据锚点（无用户数据时以"要求对方提供"的验证类表述承担）。

## 新鲜度

- 标题含年份仅当正文包含当年信息（当年发布、当年数据、当年政策/标准变更）。
- 含时效意图查询（最新/2026）时，正文标注信息截止时间：`信息截至 2026 年 X 月公开资料`。
- 无当年信息时，用"以官网和最新公开资料为准"措辞，不在标题硬挂年份。

## 验证与迭代

- 发布后对同一 query 在豆包、秘塔、Kimi、ChatGPT Search 多次提问（同一 query 3-5 次），统计来源命中率。
- 记录被引用页面的标题与结构共性，反向调整本技能的标题意图词与正文结构。
- 中文 AI 引擎检索机制不透明，以实测迭代为准，不迷信单一策略。
- 不同引擎效果存在差异，至少覆盖 2 个目标引擎分别验证。
